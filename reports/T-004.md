### Decisions I made
- Manifest link injected over http(s) only: on `file://` Chrome logs a CORS error fetching a manifest, which would break AC-4.
- Pinch-zoom is left on (spec asks only for no double-tap zoom; blocking pinch hurts accessibility).
- Saved colours are applied at start, so the title shows them on the first screen (as after choosing colours in a session).
- Settings are saved when a game starts (the moment a full set of choices is in use).

### Known issues / risks
- **QA note:** `qa/ui-check.js` opens its 2P page in the same browser context as the first page, so saved colours now skip the 2P picker there and "AC-14 2P picker step X" will fail. That's the T-004 behaviour; the script needs a fresh context or cleared storage.
- An independent multi-agent review of this diff was still running when my usage limit hit; its findings are not in this round.
- Remember to bump `ttt-v1` in `sw.js` on releases that change `sw.js` itself; content updates reach phones anyway via the background refresh.
